# Four Choices

Δωρεάν ημερήσιο κουίζ γνώσεων: 10 ερωτήσεις, 4 επιλογές, τρία επίπεδα, ελληνικά/αγγλικά.
Χωρίς χρηματικά έπαθλα, χωρίς λογαριασμούς, χωρίς εξωτερικές υπηρεσίες· παίκτες και αποτελέσματα μένουν στη συσκευή.

Free daily knowledge quiz. No prizes, no accounts, no third-party services; all data stays on the device.

Πηγές γεγονότων: Wikidata (CC0) και Wikipedia (σύνδεσμοι σε κάθε εξήγηση).
